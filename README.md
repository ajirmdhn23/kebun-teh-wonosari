# Explore Wonosari

**Explore Wonosari** is a Laravel-based agro-tourism website designed to introduce **Wonosari Agro Tourism, Singosari, Malang**. The website provides tourism information, tour packages, plantation products, events, and a visit reservation feature through a modern and responsive interface.

## Features

|                            |                                                                        |
| -------------------------- | ---------------------------------------------------------------------- |
| **Tourism Information** | Tour packages, educational activities, outbound, trekking, and camping |
| **Product Catalog**    | Tea and coffee product catalog with detailed information               |
| **Reservation**        | Visit reservation and ticket cost estimation                           |
| **QRIS Payment**        | QRIS payment simulation                                                |
| **Reservation Invoice** | Reservation summary and invoice                                        |
| **Events**              | Tourism events and activities                                          |
| **Authentication**      | User login and registration                                            |
| **Responsive Design**   | Adaptive interface for desktop and mobile                              |
